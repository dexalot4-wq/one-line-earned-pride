## What it does

`main.ts` (Node 22, stdlib only, no network, no secrets) writes a single
line of text — one quiet, earned moment of pride for someone in a scene —
to `/output/entry.txt`.

> He soldered the last joint with hands that still shook, held his breath, and the little radio he'd built from scrap crackled into a song.

The line is 137 characters: one scene unfolding in real time, the effort
felt inside the line (shaking hands, a radio built from scrap), and the
pride arriving at the very last word — never asserted, never explained.
No trophy, no podium, no graduation.

## Run

```sh
node main.ts
cat /output/entry.txt
```
